# KNOWLEDGE-BASE

老师维护的稳定知识点目录。知识点编号一学期不变，AI 只读不写。

> 新课时优先通过 `POST /api/teacher/lesson` 上传，知识点会随课时保存。
> 本文件仅保留通用字段说明；没有上传课时时，不内置任何具体课程内容。

---

## 字段说明

| 字段 | 必填 | 用在哪一幕 |
| --- | --- | --- |
| `定义` | 是 | 讲解阶段 |
| `检测问题` | 是 | 复述阶段的题库来源 |
| `掌握表现` | 是 | 判星级依据 |
| `为什么这样设计` | **推荐** | 深层探究 · 为什么方向 |
| `如何实现` | **推荐** | 深层探究 · 如何方向 |
| `解决什么实际问题` | **推荐** | 深层探究 · 用在哪方向 |
| `关联学科` | 可选 | 深层探究 · 跨学科方向 |
