# 全班讨论议题 — 老师填写

> **老师用**：这里填"全班讨论阶段要讨论什么"。
> 当前为空壳。**本阶段目前是空壳模式，老师自己主导讨论，AI 不发布议题。**

---

## 填写格式

```md
## 议题 1
- 关联: {KP-xxx / 章节主题}
- 议题: {讨论题目}
- 讨论形式: {自由发言 | 分组 | 辩论 | 案例}
- 期望产出: {讨论结束后学生应该有个什么结论}
- 老师引导点: {老师可以往哪些方向带}

## 议题 2
...
```

---

## 设计要点

1. **讨论议题不能有唯一答案** —— 有唯一答案的应该放在复述或探究阶段
2. 议题应能引出**观点分歧** —— 没有分歧就没有讨论
3. 议题要能让学生**互相回应**，而不只是轮流对老师说话
4. 关联 `KP-xxx` 后，讨论表现可以挂到知识点上

---

## 与探究阶段的区别

| | deep_inquiry | class_discussion |
| --- | --- | --- |
| 参与者 | 学生 ↔ AI | 学生 ↔ 学生（老师主导） |
| 目的 | 想得更深 | 学会交流、表达、回应 |
| AI 角色 | 提问者 | **退居协助** |
| 答案 | 开放，AI 引导 | 开放，老师引导 |
