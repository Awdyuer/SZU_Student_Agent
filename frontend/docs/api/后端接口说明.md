# 学生端接口说明

## 原则

- 所有学生发言共用 `POST /api/session/{sid}/message`。
- 前端不提交当前阶段；后端通过会话的 `host_phase` 决定教学行为。
- 开课、视频结束和教师强制切幕是控制事件，不占用 AI 消息接口。
- 前端以 `/state` 和 `/messages` 为同步真值，避免漏掉后端心跳产生的切幕和发言。

## 资源接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/student/courses` | 当前学生可见课程和课时 |
| GET | `/api/lesson?lessonId=...` | 课时详情、知识点与视频片段 |
| GET | `/api/lesson/video?lessonId=...` | 已发布视频；未配置时 `video` 为 `null` |

视频地址通过后端环境变量 `LESSON_VIDEO_URL` 配置，可选封面为
`LESSON_VIDEO_POSTER`。浏览器端不保存教师端服务密钥。

## 会话时序

```text
POST /api/session/start
  → POST /api/session/{sid}/begin
  → POST /api/session/{sid}/media/done
  → POST /api/session/{sid}/message       # 所有阶段反复使用
  → GET  /api/session/{sid}/state         # 定期同步
  → GET  /api/session/{sid}/messages      # 增量同步
  → GET  /api/session/{sid}/export?fmt=json
```

### 创建或恢复会话

```http
POST /api/session/start
Content-Type: application/json

{
  "session_id": "浏览器按课时保存的 UUID",
  "student_id": "student-001",
  "lesson_id": "ch3-process-scheduling",
  "time_scale": 1
}
```

相同 `session_id` 重复调用会返回当前状态，不会把正在进行的课堂重置为待机。

### 统一 AI 消息

```http
POST /api/session/{sid}/message
Content-Type: application/json

{ "text": "学生输入" }
```

```json
{
  "ok": true,
  "reply_text": "AI 回复",
  "phase": "recap_discussion",
  "phase_name": "复述阶段",
  "status": "running",
  "current_question": "当前问题",
  "stars": {},
  "total": 4,
  "available_actions": ["message", "media_done", "next_stage", "stop"]
}
```

`recap_discussion`、`deep_inquiry` 和 `class_discussion` 都使用该接口，不再提供
`/api/summary/review`、`/api/reflection` 或 `/api/discussion`。

## 控制与同步接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/session/{sid}/begin` | 开始课堂 |
| POST | `/api/session/{sid}/media/done` | 整段视频播放完成 |
| POST | `/api/session/{sid}/stage/next` | 教师强制进入下一阶段 |
| GET | `/api/session/{sid}/state` | 阶段、计时、问题、掌握度和可用操作 |
| GET | `/api/session/{sid}/messages?since=N` | 增量获取心跳产生的 AI 消息 |
| DELETE | `/api/session/{sid}` | 强制停止课堂 |
| GET | `/api/session/{sid}/export?fmt=json` | 导出学情 |

生产构建由 FastAPI 同源托管，不需要 CORS。单独运行 Next.js 开发服务时，将
`NEXT_PUBLIC_API_BASE_URL` 指向 FastAPI 地址。
